# 헬스 기록

헬스장 운동을 세트 단위로 기록하는 개인용 웹앱입니다. 휴대폰 브라우저에서 쓰도록 만들었고, 홈 화면에 추가하면 앱처럼 열립니다.

로그인과 서버가 없습니다. 기록은 폰의 브라우저 저장소(IndexedDB)에만 저장되고, 한 번 연 뒤에는 인터넷 없이도 동작합니다.

## 지금 되는 것

- **운동 기록**: 운동을 시작하고 종목별로 세트의 무게(kg)와 횟수를 적은 뒤 완료를 체크합니다. 웜업 세트는 따로 표시할 수 있고 볼륨 계산에서 빠집니다.
- **지난 세트 자동 채우기**: 종목을 추가하면 그 종목을 마지막으로 했을 때의 무게와 횟수가 미리 채워집니다.
- **휴식 타이머**: 세트를 완료하면 자동으로 시작합니다. 60, 90, 120초 중에서 고르고, 끝나면 진동과 소리로 알립니다.
- **기록 보기**: 지난 운동을 달별로 보고, 세트를 고치거나 기록을 지우고, 같은 종목으로 다시 시작할 수 있습니다.
- **종목**: 기본 종목 35개가 들어 있고, 내 종목을 추가할 수 있습니다.
- **백업과 복원**: 모든 기록을 JSON 파일 하나로 내보내고 다시 불러옵니다.
- **화면**: 폰의 밝은/어두운 화면 설정을 그대로 따릅니다.

## 쓰기 전에 알아 둘 점

- **기록은 폰에만 있습니다.** 브라우저의 사이트 데이터를 지우거나 폰을 바꾸면 기록이 사라집니다. 설정 화면에서 가끔 백업 파일을 받아 폰 밖(클라우드 드라이브, 메일 등)에도 보관해 주세요.
- **홈 화면에 추가해서 쓰세요.** 앱처럼 전체 화면으로 열리고, 브라우저가 오래 쓰지 않은 사이트의 데이터를 정리해 버릴 가능성도 줄어듭니다.
  - 아이폰: Safari에서 주소를 연 뒤 공유 버튼의 "홈 화면에 추가"
  - 안드로이드: Chrome 메뉴의 "홈 화면에 추가" 또는 "앱 설치"
- **아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로입니다.** Safari에서 쓰던 기록은 홈 화면 앱에 보이지 않습니다. 처음부터 홈 화면 앱에서 기록을 시작하거나, 백업 파일로 옮겨 주세요.
- **주소가 바뀌면 기록이 따라오지 않습니다.** 브라우저 저장소는 주소(도메인)마다 따로이므로, 배포 주소를 바꾸기 전에 백업하고 새 주소에서 복원해야 합니다. 항상 같은 주소로 열어 주세요.
- **휴식 타이머 알림은 앱이 화면에 떠 있을 때만 울립니다.** 쉬는 동안에는 화면이 꺼지지 않게 해 두지만(지원하는 브라우저에서), 다른 앱으로 넘어가 있으면 알림이 오지 않습니다. 돌아오면 남은 시간은 맞게 표시됩니다. 아이폰은 웹에서 진동을 지원하지 않고, 무음 모드에서는 소리가 나지 않을 수 있습니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 테스트
npm run lint       # 린트
npm run typecheck  # 타입 검사
npm run build      # dist/ 에 빌드 (타입 검사 포함)
npm run preview    # 빌드 결과를 로컬에서 확인
```

같은 와이파이의 휴대폰에서 개발 서버를 보려면 `npm run dev -- --host`로 띄운 뒤 터미널에 나오는 Network 주소를 엽니다. 오프라인 동작과 홈 화면 설치는 HTTPS로 배포한 주소에서만 확인할 수 있습니다.

### 기술

Vite, React, TypeScript, Tailwind CSS, Dexie(IndexedDB), React Router, vite-plugin-pwa, Vitest

### 구조

```
src/
  db.ts          DB 스키마와 데이터 타입
  seed.ts        기본 종목 목록
  lib/           기록 로직 (운동, 종목, 백업, 설정, 날짜와 숫자 표기)과 테스트
  rest/          휴식 타이머
  pages/         화면 (홈, 운동 중, 종목 선택, 운동 완료, 기록, 기록 상세, 설정)
  components/    여러 화면에서 쓰는 조각
```

데이터는 다섯 개의 테이블로 저장합니다.

| 테이블 | 내용 |
| --- | --- |
| `exercises` | 종목 (이름, 부위, 기구) |
| `workouts` | 운동 한 번 (시작과 끝 시각, 메모) |
| `workoutExercises` | 운동 안에서 한 종목과 순서 |
| `sets` | 세트 (무게, 횟수, 웜업 여부, 완료 여부) |
| `settings` | 설정 값 |

모든 id는 UUID 문자열입니다. 나중에 기기 간 동기화를 붙일 때 그대로 쓸 수 있게 하기 위해서입니다.

테이블 구조를 바꿀 때는 `src/db.ts`에 `this.version(2)`처럼 새 버전을 추가하고(이미 저장된 기록을 옮기는 코드 포함), 백업 파일 형식이 달라지면 `src/lib/backup.ts`의 `BACKUP_VERSION`도 올립니다.

## 배포

서버가 필요 없는 정적 사이트입니다. `npm run build`로 만든 `dist/` 폴더를 HTTPS를 지원하는 정적 호스팅에 올리면 됩니다.

Vercel을 쓰면 이 저장소를 연결하는 것으로 끝납니다. Vite 프로젝트로 자동 인식되어 따로 설정할 것이 없고(빌드 명령 `npm run build`, 출력 폴더 `dist`), `main` 브랜치가 바뀔 때마다 다시 배포됩니다. 휴대폰에서는 배포할 때마다 새로 생기는 미리보기 주소가 아니라 프로젝트의 고정 주소를 열어 주세요.

상대 경로로 빌드하고 `#/history` 같은 해시 주소를 쓰기 때문에, 도메인 루트가 아닌 하위 경로에 올려도 추가 설정 없이 동작합니다.
